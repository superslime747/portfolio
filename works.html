📊 CSV Report Generator

Приложение для автоматического анализа CSV-файлов и генерации Word-отчётов. Включает статистику, графики и оценку качества данных.

Python Pandas PyQt5 Matplotlib python-docx
Код на GitHub

Что делает программа

Загружает CSV-файл, автоматически определяет кодировку и разделитель, проводит полный статистический анализ (средние, медианы, выбросы, корреляции) и формирует готовый Word-отчёт с графиками и рекомендациями. Интерфейс на PyQt5 с тёмной и светлой темой, плюс консольный режим для автоматизации.

🔍 Trudvsem Vacancy Parser

Парсер вакансий с портала «Работа России». Сохраняет данные в SQLite, выгружает в CSV/Excel, имеет CLI и GUI.

Python requests SQLite PyQt5 pandas
Код на GitHub

Что делает программа

Использует открытое API Trudvsem без токенов и регистрации. Собирает вакансии по ключевому слову и региону, сохраняет в SQLite с защитой от дубликатов, показывает статистику (средняя зарплата, топ-города) и умеет выгружать всё в CSV или Excel. Работает и как CLI, и как GUI-приложение в тёмной теме.

🌐 Сайт-портфолио с Telegram-интеграцией

Многостраничный сайт с формой обратной связи. Заявки с формы моментально приходят в Telegram через Flask API.

HTML CSS JavaScript Flask Telegram API GitHub Pages Render
Код на GitHub

Что делает проект

Статический сайт-портфолио, размещённый на GitHub Pages, с формой обратной связи. При отправке формы данные уходят на Flask-сервер, развёрнутый на Render.com, где проходят валидацию и моментально пересылаются в Telegram через Bot API. Заявка приходит в личный чат с указанием имени, способа связи, контакта и сообщения.

Что реализовано

• Многостраничный сайт с фиксированным меню и анимированными иконками навигации.
• Форма с клиентской и серверной валидацией (имя, способ связи, контакт, сообщение).
• Flask API с эндпоинтом /api/contact и healthcheck /api/health.
• Интеграция с Telegram Bot API через requests с HTML-экранированием для защиты от XSS.
• CORS-настройка для кросс-доменных запросов между GitHub Pages и Render.
• Деплой на два бесплатных хостинга без затрат на инфраструктуру.

Технические особенности

Проект демонстрирует полный цикл разработки: от вёрстки фронтенда до деплоя backend-сервиса с внешней интеграцией. Показывает навыки работы с REST API, обработкой форм, безопасной передачей данных и настройкой CI/CD через GitHub + Render.
